#Proyecto: Odin Recipes

Este es el proyecto inicial del curso The Odin Project. El objetivo principal es construir una página web clasica de recetas para poner en practicas las bases de HTML puro.

##Habilidades demostradas: 
*Uso de etiquetas basicas de texto
*Implementación de listas ordenadas y desordenadas
Inserción de imagenes y enlaces a otras páginas web.
